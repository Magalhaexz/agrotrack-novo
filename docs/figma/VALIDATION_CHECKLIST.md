# HERDON — Checklist de validação

## Checklist obrigatório por sprint

- [ ] Figma e node correto conferidos.
- [ ] Rota atual preservada.
- [ ] Arquivo React correto preservado.
- [ ] Regras funcionais preservadas.
- [ ] Permissões e RLS preservadas.
- [ ] Dados reais e estados coerentes.
- [ ] Desktop 1440 validado.
- [ ] Desktop 1366 validado quando aplicável.
- [ ] Tablet 1024/768 validado quando aplicável.
- [ ] Mobile 375 validado.
- [ ] Mobile 320 validado quando houver diferença relevante.
- [ ] Foco visível.
- [ ] Contraste conferido.
- [ ] Navegação por teclado conferida.
- [ ] Loading conferido.
- [ ] Empty/no results conferido.
- [ ] Error conferido.
- [ ] Sem permissão conferido.
- [ ] Sem conexão/offline somente quando funcionalmente confirmado.
- [ ] Estados de atenção, crítico, atrasado, sucesso e estornado conferidos quando aplicável.
- [ ] Lint executado.
- [ ] Todos os testes executados.
- [ ] Build executado.
- [ ] `git diff --check` executado.
- [ ] Screenshot comparado ao Figma.
- [ ] Diff revisado.
- [ ] Commit contém somente o escopo do sprint.
- [ ] Push confirmado.

## Checklist final do redesign

- [ ] Conceito A implementado como padrão.
- [ ] Conceito B não virou padrão acidental.
- [ ] Shell desktop, tablet e mobile consistente.
- [ ] Todas as rotas oficiais acessíveis.
- [ ] Todos os módulos da sidebar preservados.
- [ ] Nenhuma regra de negócio foi inventada.
- [ ] Nenhum cálculo foi duplicado ou alterado.
- [ ] Nenhuma permissão foi ampliada.
- [ ] Nenhuma informação depende apenas de cor ou animação.
- [ ] `prefers-reduced-motion` implementado.
- [ ] CSS legado removido somente após confirmação de uso.
- [ ] Teste funcional autenticado concluído.
- [ ] Revisão visual do produto concluída.
