# HERDON Browser Smoke Checklist

Use this checklist for the pre-beta browser pass.

## Browser Setup

- [ ] Local app opens successfully in the browser
- [ ] Desktop large width checked
- [ ] Notebook width checked
- [ ] Tablet width checked
- [ ] Mobile width checked

## Sidebar

- [ ] Sidebar expanded state renders correctly
- [ ] Sidebar collapsed state renders correctly
- [ ] Collapse arrow stays above the HERDON logo
- [ ] Collapse arrow does not touch the logo
- [ ] Logo is not cropped
- [ ] Submenu indicators and indexes are visible
- [ ] Active state is clear in expanded mode
- [ ] Active state is clear in collapsed mode
- [ ] Sidebar scrollbar does not hide icons or labels
- [ ] User avatar area does not collide with navigation items

## Pages

- [ ] Dashboard opens without layout break
- [ ] Fazendas opens without layout break
- [ ] Lotes opens without layout break
- [ ] Animais opens without layout break
- [ ] Pesagens opens without layout break
- [ ] Sanitário / IATF opens without layout break
- [ ] Estoque opens without layout break
- [ ] Suplementação / Nutrição opens without layout break
- [ ] Financeiro opens without layout break
- [ ] Pastagens opens without layout break
- [ ] Evolução do Rebanho opens without layout break
- [ ] Indicadores opens without layout break
- [ ] Cenários opens without layout break
- [ ] Dashboard Premium opens without layout break
- [ ] Relatórios Gerenciais opens without layout break
- [ ] Configurações / Perfil / Permissões opens without layout break, if available

## Functional Checks

- [ ] No cropped text
- [ ] No overlapping cards
- [ ] No broken modal
- [ ] No table overflow
- [ ] No visible `NaN`
- [ ] No visible `undefined`
- [ ] No visible `null`
- [ ] No visible `Infinity`
- [ ] No fake data appears after login
- [ ] Active farm filter works
- [ ] Permission restrictions behave correctly
